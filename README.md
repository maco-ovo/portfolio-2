# Makoto Arata - Personal Portfolio - v2

A minimalist, highly interactive personal portfolio showcasing my journey as a Full Stack Developer.

## 🔗 Live Demo
[https://your-netlify-url.netlify.app/](https://your-netlify-url.netlify.app/) 

## ✨ Features
- **Aetheric Refinement Design**: A calm, glassmorphic UI prioritizing readability and minimal cognitive load.
- **Bento Box Layout**: A single-page dashboard architecture for quick information access.
- **Interactive Modals**: Seamless, page-less navigation to detailed project and skill overviews.
- **Smooth Animations**: Powered by Framer Motion for high-end, fluid transitions.

## 🛠 Tech Stack
- **Framework**: React (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Animation**: Framer Motion
- **Deployment**: Netlify
